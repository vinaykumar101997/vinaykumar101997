#### [Fintech-Fraud-Agent-Pro](https://github.com/VinayKumar444201-cloud/Fintech-Fraud-Agent-Pro) — AML/RAG Prototype
`Python` `LangGraph` `Gemini` `Qdrant` `GCP` `Docker` `Streamlit`

- Built an agentic RAG prototype for AML transaction analysis and retrieval of relevant regulatory guidance from unstructured documents
- Designed a multi-agent workflow with an adversarial-review step to catch inconsistencies in AI-generated compliance assessments
- Used Qdrant and Vertex AI embeddings to index and retrieve regulatory documents for context-aware analysis of simulated transaction scenarios
- Integrated web-search grounding for PEP-screening-relevant public information, surfaced for human review
- Containerized with Docker and deployed on Google Cloud, with a Streamlit interface for reviewing generated analysis
